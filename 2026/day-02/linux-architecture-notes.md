## Linux Commands

- `man`  
  To identify any command uses

- `ls`  
  List directory content

- `touch`  
  To create any file

- `cp hello.txt devops`  
  Copy text file into devops folder

- `cp -r devops devops_judwa`  
  Copy folder to another folder

- `mv devops devops_judwa`  
  Rename directory

- `ip addr`  
  Find IP address
